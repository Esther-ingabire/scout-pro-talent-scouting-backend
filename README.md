## How to run the API
1. Install Java 21, Maven, and PostgreSQL.
2. Create the database:


```sql
CREATE DATABASE scoutpro;

```
3. Open src/main/resources/application.properties and set up your postgreSQL username and password.
4. From this folder run
./mvnw spring-boot:run
5. The API starts at http://localhost:8080.
6. Import scout-pro-talent-scouting-midterm.postman_collection.json into Postman and run the requests.
